# Backpack (Lattice) — Cryptohack

**Category:** Merkle-Hellman Knapsack Cryptosystem  
**Difficulty:** Medium

---

## Challenge Overview

The challenge implements the **Merkle-Hellman knapsack cryptosystem** (a classical lattice-based trapdoor system). The private key is a **superincreasing sequence** `b = (b₁, b₂, ..., bₙ)` where each element is greater than the sum of all previous elements:
```
bᵢ > Σⱼ<ᵢ bⱼ
```

The public key is generated by:
```
aᵢ = (r * bᵢ) mod q
```
where `q > Σ bᵢ` is a prime and `gcd(r, q) = 1`.

Encryption: `ct = Σ mᵢ * aᵢ` where `mᵢ ∈ {0, 1}` are message bits.

Decryption: Compute `ct' = r⁻¹ * ct mod q = Σ mᵢ * bᵢ`, then greedy algorithm on superincreasing sequence recovers bits.

---

## Vulnerability

**Low-density knapsack** → solvable via **LLL lattice reduction**.

The density of a knapsack is defined as:
```
d = n / log₂(max(aᵢ))
```
For Merkle-Hellman, the public key elements `aᵢ` are roughly size `q` (~32-64 bits in this challenge), and `n = 8 * len(flag) ≈ 300`. So `d ≈ 300/64 ≈ 4.7` — **low density** (density < 0.94 is breakable).

The CVP formulation:
```
Find binary vector m ∈ {0,1}ⁿ such that A·m ≈ ct
```
where `A = [a₁, a₂, ..., aₙ]`.

Construct lattice basis:
```
B = [ Iₙ        0 ]
    [ A·K    ct·K ]
```
where `K` is a scaling factor (e.g., `K = 2`). The target vector `(m, 0)` is close to a lattice vector. Babai's algorithm or LLL finds it.

---

## Attack Flow

1. Parse public key `A = [a₁, ..., aₙ]` and ciphertext `ct`
2. Construct lattice basis `B` of dimension `n+1`:
   ```
   B = [ Iₙ      0  ]
       [ A·K   ct·K ]
   ```
3. Run LLL reduction on `B`
4. Short vectors in reduced basis reveal the binary message `m`
5. Convert `m` to bytes → flag

## Solution Script

```python
from sage.all import *

# From output.txt
A = [...]  # public key list (192 elements for 24-byte flag)
ct = 45690752833299626276860565848930183308016946786375859806294346622745082512511847698896914843023558560509878243217521

n = len(A)

# Construct lattice basis for CVP
K = 2  # scaling factor
B = Matrix(ZZ, n+1, n+1)

# Identity block
for i in range(n):
    B[i, i] = 1

# Last row: A*K, ct*K
for i in range(n):
    B[n, i] = A[i] * K
B[n, n] = ct * K

# LLL reduction
B_LLL = B.LLL()

# The short vectors should contain the message bits
# Check first few rows for binary vectors
for row in B_LLL:
    # Last coordinate should be small (close to 0)
    if abs(row[-1]) < 10:
        # First n coordinates should be 0/1
        bits = [int(abs(x)) for x in row[:n]]
        if all(b in (0, 1) for b in bits):
            # Reconstruct message
            m = 0
            for b in bits:
                m = (m << 1) | b
            print(bytes.fromhex(hex(m)[2:]).decode())
            break
```

---

## Why LLL Works

The vector `v = (m₁, m₂, ..., mₙ, 0)` satisfies:
```
v ≈ (0, 0, ..., 0, ct) * B  (mod lattice)
```
Actually, `v * B = (m, Σ mᵢ aᵢ K - ct K) = (m, 0)` exactly! So `v` is in the lattice.

But `v` has norm `√n`. LLL finds short vectors; the secret `v` is shorter than random lattice vectors with high probability for low-density knapsacks.
